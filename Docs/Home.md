### 1. Development
There are two primary methods for creating custom beds in the system:
- [Bed Creation via JSON](./Development/BedCreationViaJSON.md)
- [Bed Creation via Code](./Development/BedCreationViaCode.md)

If you developed custom beds using the older `.json` format, please refer to the [Update from .json to .bed](./Development/UpdateFromJsonToBed.md) guide for instructions on transitioning to the new `.bed` format.

Each method provides flexibility depending on the developer's preference and the complexity of the bed being created. For detailed instructions and examples, please refer to the respective sections linked above.
